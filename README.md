### What I work on

- **Ad-tech platforms** — ~30 production services around ad operations: campaign / creative automation on the Meta Marketing API and Google Ads API, bulk ad-setting and keyword optimisation, reporting exports.
- **Data pipelines & batch** — sync jobs between ad platforms, PostgreSQL and Snowflake; job launchers and workers on ECS / Lambda driven by EventBridge and Step Functions; pandas / openpyxl reporting.
- **LLM-powered features** — keyword generation and content workflows on Claude (Anthropic) and OpenAI, with LangChain and MCP tooling.
- **AI-driven development** — helping shape the team's AI-assisted engineering process: Claude Code workflows, automated quality gates and spec / handover docs generated from code.
- **Browser automation** — Selenium / Playwright tooling that drives ad-platform consoles where no API exists.
- **Cross-border delivery** — working daily with Japanese product teams; specs, reviews and handover in a JP ↔ VN setup.

### How I work

- Read the existing system before changing it; prefer small, reviewable PRs over big-bang rewrites.
- Tests and observability (Sentry, structured logs, Slack alerts) are part of the feature, not an afterthought.
- Write things down — design notes and runbooks outlive the person who wrote the code.
