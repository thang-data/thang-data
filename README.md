### What I work on

- **Ad-platform integrations** — building services on top of the Meta Marketing API: campaign / ad set / creative automation, data sync, and reporting.
- **Data pipelines** — ingesting, normalising and serving marketing data; SQL-heavy work on PostgreSQL and warehouse tooling.
- **Cloud backends** — Python, TypeScript and Go services deployed on AWS (ECS, Lambda, S3, RDS) with Docker and CI/CD.
- **Cross-border delivery** — working daily with Japanese product teams; specs, reviews and handover in a JP ↔ VN setup.

### How I work

- Read the existing system before changing it; prefer small, reviewable PRs over big-bang rewrites.
- Tests and observability are part of the feature, not an afterthought.
- Write things down — design notes and runbooks outlive the person who wrote the code.
